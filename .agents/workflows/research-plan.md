# /research-plan

Workflow for formulating structured implementation plans before undertaking research code modifications.

## Instructions
1. Analyze the requested feature, experiment modification, or refactoring task.
2. Produce a clear implementation plan detailing:
   - Specific target files to modify, create, or delete.
   - Core technical changes and design patterns.
   - Identified research risks, potential confounds, and impact on existing baselines.
   - Verification plan and unit/integration tests to execute.
3. **STOP and wait for user approval before modifying code or executing setup actions.**
