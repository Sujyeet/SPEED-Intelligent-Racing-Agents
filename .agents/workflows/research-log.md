# /research-log

Workflow for logging research progress at the end of a session.

## Instructions
1. Summarize the work completed during the current session.
2. Record all modified, created, or deleted files.
3. Record key technical decisions in `docs/DECISION_LOG.md`.
4. Record tests run and tests not run.
5. Record remaining technical uncertainties or open questions.
6. Identify exactly **one** recommended next action for the user.
