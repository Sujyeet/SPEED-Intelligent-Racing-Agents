# /document-code

Workflow for explaining and documenting source code without modifying implementation logic.

## Instructions
1. Inspect the specified C# class, method, or configuration block.
2. Provide a technical breakdown covering:
   - Component responsibilities and inputs/outputs.
   - External dependencies and assembly boundaries.
   - Edge cases and error handling.
   - Relevance to research variables and experimental metrics.
3. **Do not rewrite or modify the source code during this workflow.**
