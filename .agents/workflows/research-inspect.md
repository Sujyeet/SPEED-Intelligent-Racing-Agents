# /research-inspect

Workflow for safe inspection of research code without making modifications.

## Instructions
1. Inspect the target source code, scene settings, or ML configuration files requested by the user.
2. Explain in detail how the inspected system works, highlighting control flow, state transitions, and component interactions.
3. Identify all research variables affected (e.g., observation vector dimensions, action space mappings, reward scaling factors, vehicle dynamics).
4. **Make no code or file changes during this workflow.**
