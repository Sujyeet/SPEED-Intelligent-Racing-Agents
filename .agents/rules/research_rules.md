# Research Environment Workspace Rules

- **Environment Identity**: This is a Unity AI research environment (`SPEED-Intelligent-Racing-Agents`).
- **Separate Full-Game Folder**: The full-game production folder is completely separate outside this workspace. Never inspect, access, modify, copy from, or synchronize with that folder.
- **Inspection First**: Always inspect relevant files and understand the current system before editing or proposing changes.
- **Explain System**: Explain the architecture and behavior of the current system before proposing modifications.
- **Propose Implementation Plan**: Produce a clear implementation plan before undertaking non-trivial changes.
- **Request Approval for Risky Operations**: Obtain explicit user approval before conducting any risky, destructive, or breaking operations.
- **Fact Integrity**: Never invent research results, statistics, citations, baseline figures, or experiment outcomes.
- **Attribution & Origin**: Clearly distinguish between pre-existing codebase components, open-source framework code, AI-generated suggestions, user modifications, and novel research contributions.
- **Experimental Tracking**: Record all code modifications affecting observations, action spaces, reward functions, vehicle physics, track geometry, spell mechanics, agent behavior, or evaluation metrics.
- **Change Reporting**: Report all modified files, executed tests, skipped tests, and remaining technical risks upon task completion.
- **Code Simplicity**: Prefer simple, readable, and clean code over unnecessary abstractions.
- **Library Preservation**: Do not rewrite PPO algorithms, ML-Agents core packages, or third-party libraries unless explicitly requested.
- **Variable Isolation**: Do not modify multiple experimental variables simultaneously without explicitly documenting the resulting experimental confound.
- **Communication Focus**: Ask one focused question at a time when seeking user clarification or approval.
- **Documentation Updates**: Update relevant research documentation (`docs/`) after completing any meaningful research task or code modification.
